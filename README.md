# Judge Laugh — Office Printer

A TypeScript program (Node 22) that writes one original joke about office life to `/output/entry.txt`. The joke treats the office printer as a coworker with moods, giving it a performance review — and an ending nobody in the office saw coming.

Run with `node main.ts`. The output is a single line, under 200 characters, ready for the AI judge.
